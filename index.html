Compare the three approaches

All three pages use CSS. Tailwind and Bootstrap provide classes for styling, and the routine builder uses custom rules in its own stylesheet.

Tailwind

Tailwind also styles an HTML element using class="", with individual styles like class="rounded-full bg-blush". The rule for the color of bg-blush is in tailwind.css.

Pros
Control over layout, spacing, and colors helps you match a custom design.
Cons
Class lists can get long in the HTML, and I need to rebuild this project’s CSS after I change its Tailwind classes.
Good for
Branded storefronts like Skins, portfolios, and campaign websites that need a custom layout and visual style.
Check out the Tailwind page

Bootstrap

Bootstrap styles an HTML element using class="" with a pre-styled class like btn. It applies several styles at once, including padding, font settings, rounded corners, and hover transitions. The btn style is defined in bootstrap.min.css and customized in styles.css.

Pros
Ready-made styles for buttons, forms, and tables help you build a consistent page quickly.
Cons
A custom design can require extra CSS for colors, spacing, and component styles.
Good for
Admin dashboards, booking forms, and internal tools where standard components cover most of the design.
Check out the Bootstrap page

Plain CSS and JavaScript

My interactive page uses plain JavaScript, HTML, and CSS. The CSS controls how the page looks, and JavaScript updates the routine when I change the options.

Pros
I can style the page directly, and it runs without installing a framework or building the CSS.
Cons
I have to write and maintain the CSS for layout, spacing, and reusable styles myself.
Good for
Small sites or interactive demos with a few controls, like my routine builder.
Check out the routine builder
