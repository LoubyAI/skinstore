Skins is an AI-assisted web development project. It explores how Tailwind and Bootstrap can style the same skincare storefront.

I used Codex to help build and refine both storefronts and to create an interactive routine builder with plain JavaScript.

About the project

My project is a skincare storefront for Skins. Visitors can browse serums, cleansers, creams, and lotions, search for products, save favorites, and add items to a shopping bag.

I used the same products, colors, and layout in both storefronts so you can see how Tailwind and Bootstrap handle the same design.

Compare the three approaches

All three pages use CSS. Tailwind and Bootstrap provide classes for styling, and the routine builder uses custom rules in its own stylesheet.

Tailwind

Tailwind also styles an HTML element using class="", with individual styles like class="rounded-full bg-blush". The rule for the color of bg-blush is in tailwind.css.

Pros
Control over layout, spacing, and colors helps you match a custom design.
Cons
Class lists can get long in the HTML, and I need to rebuild this project’s CSS after I change its Tailwind classes.
Good for
Branded storefronts like Skins, portfolios, and campaign websites that need a custom layout and visual style.
Check out the Tailwind page

Bootstrap

Bootstrap styles an HTML button with a pre-styled class. For example, class="btn" applies several styles at once, including padding, font settings, rounded corners, and hover transitions. The btn style is defined in bootstrap.min.css and customized in styles.css.

Pros
Ready-made styles for buttons, forms, and tables help you build a consistent page quickly.
Cons
A custom design can require extra CSS for colors, spacing, and component styles.
Good for
Admin dashboards, booking forms, and internal tools where standard components cover most of the design.
Check out the Bootstrap page

Plain CSS and JavaScript

My interactive page uses plain JavaScript, HTML, and CSS. The CSS controls how the page looks, and JavaScript updates the routine when I change the options.

Pros
I can style the page directly, and it runs without installing a framework or building the CSS.
Cons
I have to write and maintain the CSS for layout, spacing, and reusable styles myself.
Good for
Small sites or interactive demos with a few controls, like my routine builder.
Check out the routine builder

How both pages style “Shop now”

Tailwind
<button
  type="button"
  data-open-product="serum"
  class="mt-3 min-h-10 rounded-full bg-blush px-3
         text-xs uppercase hover:bg-white md:mt-[.85vw]
         md:min-h-[clamp(1.6rem,2.16vw,2rem)] md:px-2"
>
  Shop now
</button>

Each class applies one style. rounded-full makes the button pill-shaped, bg-blush sets the background, and px-3 adds horizontal padding. hover:bg-white makes the background white on hover. Tailwind generates the rules in tailwind.css.

Bootstrap
<button
  type="button"
  data-open-product="serum"
  class="shop-button btn rounded-pill text-uppercase"
>
  Shop now
</button>

Bootstrap’s btn applies several base styles at once, and rounded-pill gives the button its shape. The custom shop-button rule in bootstrap/styles.css sets the padding, blush background, and white hover color.
